# LANE 2.4 — Branding + Smart PDF Import

Nieuwe functies in deze versie:

- Persoonlijke branding geïntegreerd:
  - banner in de sidebar
  - eigen app-icoon voor browser, homescreen en PWA
- Slimmere trainingsimport:
  - ondersteunt PDF, DOCX en TXT
  - behandelt pagina 1 van PDF standaard als weekoverzicht
  - behandelt volgende pagina's als individuele trainingen
  - probeert per trainingspagina duur (minuten) en totale meters te herkennen
  - toont een bewerkbare preview vóór toevoegen aan de planning
  - slaat geplande meters mee op bij geïmporteerde zwemtrainingen
- Planning toont nu ook geplande meters bij zwemblokken
- Auto-update en offline-ondersteuning blijven aanwezig

## Publiceren

Vervang de bestaande bestanden in je GitHub-repository door de inhoud van deze map en commit de wijzigingen.

## Opmerking

De PDF-import is heuristisch. Ze werkt het best met tekst-PDF's en kan bij complexe layouts nog handmatige correctie vragen.
