# LANE 2.5 — Athlete × Student OS

- Officieel logo: witte buitenrand transparant, appicoontjes en banner geïntegreerd.
- PDF-trainingsimport: eerste pagina weekoverzicht, volgende pagina’s sessies; bovenaan ochtend/avond + exacte datum; onderaan duur, meters en AEC1/AEC1+/AEC2/AEC3/ANC/ANP.
- Geen omschrijvingsveld bij import. Bewerkbaar preview-overzicht met dagdeel, datum, starttijd, minuten, meters en trainingstype.
- Trainingen worden gepland, niet als uitgevoerd gelogd. Bestaande localStorage blijft behouden.
- Auto-update via service worker, netwerk vereist om nieuwe versie op te halen.

**Let op:** PDF-herkenning is patroon-gebaseerd en nog niet afgestemd op een echt voorbeeld van jouw trainings-PDF. Controleer de import vóór opslaan. Ochtend/avond-starturen zijn voorlopige aannames (06:00/17:00) als het schema geen starttijd vermeldt.
